## The 12 agents

Each agent does one focused task well. Built so a sales rep can install one, get value from it, and only add the next when needed.

| # | Agent | What it does | Slash command |
|---|---|---|---|
| 01 | Follow-Up Sequence | 5-touch follow-up plan for a quiet deal | `/follow-up` |
| 02 | No-Show Recovery | 3-touch sequence for missed appointments | `/recover` |
| 03 | Sales Email Generator | One polished email — quote, trade-in, thank-you, etc. | `/email` |
| 04 | Objection Handler | 3 framings + next step for any objection | `/objection` |
| 05 | Objection Prep | Predict top 5 objections before a meeting | `/prep` |
| 06 | Negotiation Coach | Tactical move-by-move negotiation map | `/negotiate` |
| 07 | Pipeline Review | Strategic read on which deals close, which die | `/pipeline` |
| 08 | Priority List | Daily / weekly tactical action list | `/priorities` |
| 09 | Proposal Builder | Professional 1–2 page sales proposal | `/proposal` |
| 10 | Customer Recap | Post-meeting structured capture + next steps | `/recap` |
| 11 | Cold Outreach | One sharp cold message (email / SMS / LinkedIn) | `/cold` |
| 12 | Test Drive Follow-Up | The 48-hour post-test-drive message | `/test-drive` |

## The 8 plugins (reference docs)

Plugins are knowledge files you load into your Claude project so the agents have richer context. Each agent gets sharper when paired with the right plugins.

| Plugin | What it gives Claude |
|---|---|
| Deal Summary | A structured "deal sheet" template per active deal |
| Lead Re-Engagement | Framework for waking up dormant leads (30–180 day+) |
| Vehicle Talking Points | What to lead with for each major vehicle category |
| Weekly Recap | Template that turns a Friday brain-dump into a structured weekly summary |
| Financing Summary | How to talk finance / lease / cash without getting yourself in trouble |
| Customer Profile | 8 buyer archetypes + how to communicate with each |
| Trade-In Framework | Conversation + structure for presenting trade-in offers |
| Phone Script Library | Phone scripts for the calls reps avoid most |

## Start here

1. Read `SETUP-GUIDE.md` (10 min)
2. Install the **Follow-Up Sequence** agent — it's the most-used and gets you producing dealership-quality output fastest
3. Use it on a real deal in your pipeline this week — the Friday quote follow-up is the perfect first test
4. Once it's clicked, add 2–3 more agents from the table above based on what fits your week
