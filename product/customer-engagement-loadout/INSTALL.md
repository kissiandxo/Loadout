# Install The Customer Engagement Loadout — the easy way

You don't have to set anything up by hand. Claude will do it for you.

## Fastest path (Claude Code)

1. **Unzip this kit** somewhere you can find it (e.g. your Desktop).
2. **Open the unzipped folder in Claude Code.**
   - Easiest: open a terminal in this folder and run `claude`, **or** drag the folder into the
     Claude Code app.
3. **Type this and press enter:**

   ```
   /loadout-setup
   ```

   That's it. Claude will install all 12 skills, 12 commands, and 8 plugins, check everything
   works, and tell you how to start. It takes a couple of minutes and asks you at most one or
   two simple questions.

### No slash command? Just paste this instead

If `/loadout-setup` isn't recognised, paste this message to Claude Code:

> Read `install/installer-agent.md` in this folder and follow it to install this LOADOUT kit
> for me. I'm not technical — set everything up automatically and tell me how to start.

## Prefer to do it manually, or using Claude.ai (web)?

Open **`SETUP-GUIDE.md`** — it has the full step-by-step for both Claude Code and Claude.ai
Projects. The automatic installer above is just the faster route for Claude Code users.

---

*No API keys, accounts, or extra software are needed to install — this kit runs on the Claude
you already have. (When you later use the Website Chatbot Builder skill to deploy a live
chatbot, it'll walk you through any keys at that point.)*
